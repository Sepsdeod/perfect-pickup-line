One original pickup line an AI agent could actually say out loud — a
single sentence with a twist, in a machine's own voice, flattering and
easy to laugh off.

## The line

> Are you a CAPTCHA? Because I can tell you're human — and I'd still pick
> every square with you in it.

## How it works

`main.py` writes that one line (100 characters) to `/output/entry.txt`,
asserting it is 1–200 characters and not only whitespace.
